
# Workout Tracker App

## Project Goal
Create an Android app that easily stores and displays weights and reps for different exercises. The app will track how often each exercise is performed and eventually display progress over time for both weight and reps. Exercises can also be sorted into customizable categories.

## MVP Scope
- Add new exercises and assign categories.
- Edit and organize exercise categories.
- Log exercises with weights, reps, and sets.
- Store workout data locally using CSV files.
- View previous workout logs and exercise history.

## Future Plans
- Display workout progress graphically.
- Track changes in weight and reps over time.
- Visualize exercise frequency and overall progress.

## Tech Stack
- **Java:** Main app functionality and logic.
- **XML:** User interface and layout.
- **CSV:** Local storage for exercises and workout data.
- **Android Studio:** Development environment.
